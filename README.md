# OETBook Lesson Engine

Converts existing Persian-language recorded OET lessons into English
interactive lessons.

## Status

Phase 0 — Discovery. Nothing is decided yet. No pipeline code exists.

## What this is not

- Not a website
- Not an LMS
- Not a video editor

The output is structured content, not video files.

## Rules

See `AGENTS.md`. Those rules are binding for both humans and AI agents.

## Source material

~60 recorded sessions, Persian narration over English Canva slides,
with live pen annotation captured by screen recording.

Media files never enter this repository.
