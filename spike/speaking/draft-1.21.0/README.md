# The site's DRAFT speaking contract (ADR 053)

`speaking.schema.json` is a byte-for-byte copy of the draft schema for the site's Speaking Coach items,
taken read-only from oetacademy-web:

- branch `feat/speaking-coach-prototype`, commit `9888b932debc8d101d825e7249fae1733940bd46`
- path `packages/shared/drafts/speaking/speaking.schema.json`
- a draft of contracts 1.21.0 (oetacademy-web #265, draft PR #264), **not released**

It is used only by `spike/scripts/speaking_items.py`, the one module that knows the draft's shape.
While `speaking_items.RELEASED` is False, `publish_lesson.py` refuses to build any package or draft of a
lesson with speaking units.

When the site releases the contracts, this copy is replaced by the released contracts zip (pinned like
the others in `spike/contracts/`), `speaking_items.py` is brought into line with it, and RELEASED is set.
Do not edit this file by hand: copy it again from the site's repository.
